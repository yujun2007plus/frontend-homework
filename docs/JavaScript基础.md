# JavaScript 基础笔记

## 变量声明

- `var`：函数作用域，有提升
- `let` / `const`：块级作用域，无提升（TDZ）

## 数组常用方法

- `map` / `filter` / `reduce` / `forEach`
- `find` / `some` / `every`

## 事件

- `addEventListener(type, handler, options)`
- 事件冒泡与捕获：`useCapture` 参数

## 异步

- Promise：`then` / `catch` / `finally`
- `async` / `await` 语法糖
