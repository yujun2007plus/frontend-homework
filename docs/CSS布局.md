# CSS 布局笔记

## Flexbox 常用属性

- 容器：`display: flex`、`justify-content`、`align-items`、`flex-wrap`
- 子项：`flex`、`order`、`align-self`

## Grid 常用属性

- `grid-template-columns`、`grid-template-rows`
- `gap`、`grid-area`

## 居中方案

1. Flex：`display: flex; justify-content: center; align-items: center`
2. Grid：`place-items: center`
3. 绝对定位 + `transform: translate(-50%, -50%)`
